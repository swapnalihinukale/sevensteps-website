# Stop Slop

Read [SKILL.md](SKILL.md) and its references when editing prose. [Hardik Pandya](https://hvpandya.com) wrote the original skill; the [MIT licence](LICENSE) and source commit are retained.

The local example file replaces one em dash with a comma. [PROVENANCE.json](PROVENANCE.json) records its original and edited hashes. Follow [the Seven Steps writing guide](../../../docs/COPY-AND-VOICE-SPEC.md) for project copy. No runtime or global installation is needed.
